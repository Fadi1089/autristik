# Game audio credits

All included clips are CC0 1.0 assets, downloaded on 2026-10-12 and redistributed locally.
The source files have only been renamed. The music receives a 40 ms boundary crossfade during
playback; the bundled OGG file itself is unchanged.

Menu navigation uses `menu-nav.ogg`, originally `click_002.ogg` from
[Kenney — Interface Sounds](https://kenney.nl/assets/interface-sounds), under CC0.
Playback lowers its pitch to 75% speed, filters high frequencies above 1.2 kHz, and adds a
6 ms attack / 12 ms release envelope for a softer cue. The source OGG is unchanged.

Background music uses `sunset-walk.ogg`, originally `SunsetWalk.ogg` by
[Kilua Boy — Sunset Walk](https://opengameart.org/node/87082), under CC0.
The source page describes it as a quiet ambient loop. The original lasts 76.8 seconds;
the playback loop lasts 76.76 seconds after the boundary blend.

The water-drop option uses a short bubbling/plop clip from rubberduck's pack.
Kenney's original license notices are included in this directory.
rubberduck's source page explicitly lists CC0 as the license.

[CC0 1.0 Universal dedication](https://creativecommons.org/publicdomain/zero/1.0/)

Special-tile cues (void suction, gold, bedrock, bronze, silver and diamond) are original
procedural effects generated by `src/audio/tileSounds.ts`, using shaped noise and damped
oscillators. They do not use additional recordings or external assets.
